## 2. 改了什麼

### Build / 工程

| 檔案 | 變更 |
|---|---|
| `package.json` | `dev/build/preview` 改指 Vite（原本錯指 Next.js）；加 `lint`、`typecheck` script |
| `eslint.config.js` | scope 限 `src/**`，ignore `api/`、`dist/`、`node_modules/` |
| `src/utils/bazi.ts` | `Promise<MatchResult>` 取代 inline anon type（A2 修）|
| `src/App.tsx` | useEffect init → useState lazy initializer |
| `src/components/MyDataForm.tsx` | 同上 + `<label htmlFor>` + `aria-required` + `role="alert"` |
| `src/components/PartnerList.tsx` | 同上 + `<label className="sr-only">` + `aria-required` |
| `src/components/HistoryPanel.tsx` | useEffect init → useState lazy；empty state 改 actionable（icon + title + desc）|
| `src/components/MatchResultCard.tsx` | setState-in-effect 用 `queueMicrotask` 包起來（React 19 rule）|

### a11y / 設計

| 檔案 | 變更 |

| `src/index.css` | `:focus-visible` global ring；`--color-muted` 從 `#a78bfa` 改 `#c4b5fd`（WCAG AA 對比）|
| `public/robots.txt` | 新建（`User-agent: * / Allow: /`）|
